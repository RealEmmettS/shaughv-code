Use this everywhere Any project built on the SHAUGHV design system uses this loader by default — full-page boot, route transitions, async work, skeletons. Do not substitute another spinner or use a framework default.
Only color is tweakable The loader inherits its fill from the host element's CSS color. Set it to var(--accent), var(--fg), or anything from the palette. Geometry, timing, and the goo morph are locked.
Drop to #46 only when… The surface is <120 px wide or the load is expected to resolve in <2 s. Otherwise the full morph is the right call — its length is intentional, not a bug.
