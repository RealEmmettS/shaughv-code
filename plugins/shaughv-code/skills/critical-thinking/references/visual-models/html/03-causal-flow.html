Causal flow diagram

You need to understand WHY something happens, not just what — trace cause to effect and find where to intervene.

Reusable reference template. Edit the four node labels and the notes array. Click a node to read its role and see the root-cause link highlighted.

What it surfaces: tracing the chain link by link shows the failure is downstream of the real cause. The cheapest, highest-leverage fix goes at the earliest broken link (the misread) — not at the symptom.
