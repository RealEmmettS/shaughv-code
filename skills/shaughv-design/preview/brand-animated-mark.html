Animated · default Wordmark holds 10 s, undraws (deco first, then letters reversed), pauses 3 s, the icon-only mustache + glasses draws in, holds 10 s, undraws, pauses 3 s, wordmark redraws.
Static fallback For frameworks that can't run the JS file (PPTX, PDF, plain image consumers), use assets/SHAUGHV-Official.svg as a static drop-in. Same path data, no motion.
Icon variant For ≤ 48 px surfaces (favicons, avatars) where letters would be illegible, use assets/SHAUGHV-Favicon-*.svg or pass icon-only to the mark element.
HOLD 10 000ms · PAUSE 3 000ms · W_STAGGER 650ms · W_STROKE 700ms · W_FILL 400ms
I_STAGGER 1 800ms · I_STROKE 1 600ms · I_FILL 600ms · EASE cubic-bezier(0.16, 1, 0.3, 1)
Drop-in integration — one script tag, one element. Color via currentColor. Honors prefers-reduced-motion: reduce by falling back to the static wordmark. Full recipe lives in BRANDMARK.md at the design-system root.
